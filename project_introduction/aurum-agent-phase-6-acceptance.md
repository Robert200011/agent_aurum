## 2. 阶段状态

阶段六的代码、配置、脚本、CI、运行手册和本地演练证据已经形成闭环，并已通过 GitHub
PR #11 squash 合入 `master`，当前功能基线为 `e8aa6ea`。由于开发机不能替代真实生产
环境，以下项目是上线前操作门禁，不作为进入阶段七设计与开发的阻塞项：

- 使用真实 Chat/Embedding/Reranker Provider 完成候选冒烟；
- 在目标单机规格运行 `single-node-release` 负载并锁定容量基线；
- 配置正式域名、TLS、镜像 digest、外部密钥和异地备份介质；
- 由授权人员审核证据并批准生产切流。

各批次详细证据见 P6.1～P6.5 验收报告；生产操作见 `deploy/release-runbook.md` 和
`deploy/backup-policy.md`。

项目当前约定不跟踪本地 `tests/`，因此 GitHub 后端工作流的绿色状态不等同于完整 Pytest
回归；各阶段完整测试结果以受控本地环境的验收记录为补充依据。
